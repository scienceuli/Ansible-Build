# RClone role

Sync files with RClone.

## Usage

Configure the role.

```yml
rclone_sync:
- id: "Run job sync folder"
  command: "copy"
  source_provider: filesystem
  source: /mnt/snas1/publication/
  dest_provider: filesystem
  dest: /usr/share/birt01/reports
  minute: "*/10"
- id: "offsite backup"
  name: "remote"
  command: "copy"
  source_provider: filesystem
  source: /var/tmp/odoo.zip
  dest: remote:/home
  dest_provider: sftp
  host: sftp.example.com
  user: backup
  pass: f669HJNLPJTsG61SVuwrqkKCjmvHRG_3jzJ_pGdmO7B9yBAw # password obscured with rclone
  hour: "3"
- id: "Offsite sync to storage box"
  name: storagebox
  command: sync # copy, copyto or sync
  source_provider: filesystem
  source: /mnt/sdb/
  dest: "storagebox:sdb" # subfolder: sync deletes everything not in source, incl. .ssh/ in the root
  dest_provider: sftp
  host: u12345.your-storagebox.de
  port: 23 # default: 22
  user: u12345-sub1
  key_file: /root/.ssh/storagebox_ed25519 # generated by the role, public key is printed
  known_hosts_file: /root/.ssh/known_hosts # enables host key verification
  host_keys: # pinned into known_hosts_file (all types the server offers)
    - "[u12345.your-storagebox.de]:23 ssh-ed25519 AAAA..."
  options: --exclude '/lost+found/**' # extra rclone flags (quote globs: cron runs them through sh)
  hour: "5"
```

And include it in your playbook.

```yml
- hosts: rclone
  roles:
  - role: rclone
```
